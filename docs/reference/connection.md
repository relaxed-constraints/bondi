# Connection settings

Immutable settings shared by executors, loaders and index operations. Obtain
settings from `Deployment.connection` or construct them directly. See the
[connection guide](../connections.md) for lifecycle and ownership examples.

::: bondi.MongoConnection
    options:
      show_root_heading: true
      heading_level: 2

::: bondi.CouchbaseConnection
    options:
      show_root_heading: true
      heading_level: 2
