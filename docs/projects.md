# Projects

These projects use BONDI and provide starting points for your own research.

### BONDI Demo Project

A guided example of reproducible MongoDB experiments: prepare a dataset, generate
a query workload, benchmark different index sets, and analyse the results in a
Jupyter notebook. It combines BONDI with Yanex experiment tracking and includes
step-by-step tutorials and a Markdown slide deck for progress updates.

- Visit [BONDI Demo Project](https://github.com/relaxed-constraints/bondi-demo-project) on GitHub

### BONDI Empty Project

A minimal starter for those who want to build their own project from scratch.
It uses the same dependencies and directory structure as the demo project, with
a small hello world function, CLI, Yanex experiment, notebook and test to show how the
pieces fit together. A Markdown slide deck is included for progress updates.

- Visit [BONDI Empty Project](https://github.com/relaxed-constraints/bondi-empty-project) on GitHub

### BONDI JSON Bench

An analytical benchmark for MongoDB and Couchbase. Generate travel data, translate
shared query templates for both databases, and compare throughput, query runtimes,
and outcomes across scale factors and client counts. It uses BONDI for database
deployments, data loading, and workload execution, with a standalone CLI, Yanex
experiment scripts, and notebooks for analysis.

- Visit [BONDI JSON Bench](https://github.com/relaxed-constraints/bondi-json-bench) on GitHub
- Check the [documentation](https://relaxed-constraints.github.io/bondi-json-bench/) for details
