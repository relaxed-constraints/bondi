# Projects

These projects use BONDI and provide starting points for your own research.

## bondi-demo-project

A guided example of reproducible MongoDB experiments: prepare a dataset, generate
a query workload, benchmark different index sets, and analyse the results in a
Jupyter notebook. It combines BONDI with Yanex experiment tracking and includes
step-by-step tutorials and a Markdown slide deck for progress updates.

[View bondi-demo-project on GitHub](https://github.com/relaxed-constraints/bondi-demo-project)

## bondi-empty-project

A minimal starter for students who want to build their own project from scratch.
It uses the same dependencies and directory structure as the demo project, with
a small greeting function, CLI, Yanex experiment, notebook and test to show how the
pieces fit together. A Markdown slide deck is included for progress updates.

[View bondi-empty-project on GitHub](https://github.com/relaxed-constraints/bondi-empty-project)
